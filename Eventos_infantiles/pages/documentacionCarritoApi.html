Combinación de APIs en el Sistema

Cómo se integran las APIs

El sistema combina datos de ambas APIs para crear una experiencia completa:

  1. Obtiene imágenes de eventos de Pexels API
  2. Recupera datos de salones disponibles de MockAPI
  3. Combina ambos conjuntos de datos emparejándolos por índice
  4. Muestra salones con sus imágenes correspondientes
